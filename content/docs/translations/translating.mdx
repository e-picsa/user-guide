## Workflow

1. Select the **locale** — the list refreshes automatically.
2. Work through rows with an empty translation cell. The **Tool** and **Context** columns tell you where the string appears.
3. Click a row to open the editor dialog, enter the translation and save.
4. Tick **Include translated** when you want to review or fix already-translated rows.

A progress indicator tracks how much of the locale is complete.
