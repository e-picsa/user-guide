## XLSX workflow

1. **Download Template** to get the expected columns.
2. Fill in translations offline and **drop the file** (or browse to it).
3. Review and confirm the import; strings then appear in the [translations list](./translating).

## App JSON workflow

Drop app-format JSON files to import them directly, or use **Export All** to download everything — useful for backups or moving content between environments.
