## Understanding the columns

| Column | Meaning |
| ------ | ------- |
| Type / Cover Image | File kind (PDF, video, document) and thumbnail |
| Title | Display name in the field app |
| Size | Download size, kept small for offline use |
| Languages | Which app languages the file serves |
| Collections | Groupings this file belongs to — click a cover to open the collection |
| Updated | Last modification date |

Click any row to edit the file's metadata, replace the upload or delete it — see [Managing files](./files-manage).
