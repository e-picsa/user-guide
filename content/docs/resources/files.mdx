## Understanding the columns

| Column | Meaning |
| ------ | ------- |
| Type / Cover Image | File kind (PDF, video, document) and thumbnail |
| Title | Display name in the field app |
| Size | Download size, kept small for offline use |
| Languages | Which app languages the file serves |
| Collections | Groupings this file belongs to — click a cover to open the collection |
| Updated | Last modification date |

Click any row to open it — see [Managing files](./files-manage) for what you can change.

## Who can do what

<AccessSummary>
  <AccessRow roles="viewer">Browse the list and open any file — without an editing role the form opens read-only as **View Resource**.</AccessRow>
  <AccessRow roles="editor">See **Add Resource** and upload new files; edit or delete owned files (`resources.editor`) — see [Managing files](./files-manage).</AccessRow>
  <AccessRow roles="admin">Edit or delete any file, and audit field-app data in [Resources data admin](./data-admin) (`resources.admin`).</AccessRow>
</AccessSummary>
