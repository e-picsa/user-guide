## Steps

1. **Upload the file** (PDF, MP4, MP3 or image) or select an existing file from country storage. File details — name, type and size — fill in automatically.
2. **Add a cover image** so the file is recognisable in lists.
3. Enter a **Title** and optional **Description**, and choose the **Language**.
4. **Save Resource** (below the visible area — scroll down). The file is upserted and appears in the list and in linked collections immediately.

Editing an existing file (shown here for completeness) offers the same fields plus **Delete Resource** for files you can edit and, for externally-hosted files, a **View Resource** link.

<Callout type="warning">
  Deleting a resource removes it from the dashboard and from future app data
  releases. Already-downloaded copies on devices are unaffected.
</Callout>

## Who can do what

<AccessSummary>
  <AccessRow roles="viewer">Open any row, but the form is read-only **View Resource** — uploads, fields and buttons are disabled.</AccessRow>
  <AccessRow roles="editor">Upload new files; edit or delete owned files, while files owned by someone else stay read-only (`resources.editor`).</AccessRow>
  <AccessRow roles="admin">Edit or delete any file regardless of owner; deletion is permanent — see above (`resources.admin`).</AccessRow>
</AccessSummary>
