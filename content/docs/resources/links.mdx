<Callout type="info">
  **Add Link** (`resources.admin`) sits at the top of the page above the
  visible area — scroll up to register a new URL.
</Callout>

## Link types

The type icon tells farmers what to expect: social (groups and pages), web (sites and services) or app (store listings). Each row shows the title, a short description, the URL and when it was last modified.

## Adding or editing a link

**Add Link** (or click a row) opens the link editor, which currently asks only for the **URL** (validated as a web address) alongside the country. Save to publish it to the list.

<Callout type="info">
  Links point outward — unlike files, they need connectivity to open. Prefer
  file resources for content farmers must reach offline.
</Callout>
