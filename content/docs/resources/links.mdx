## Link types

The type icon tells farmers what to expect: social (groups and pages), web (sites and services) or app (store listings). Each row shows the title, a short description, the URL and when it was last modified.

## Adding or editing a link

**Add Link** (or click a row) opens the link editor (`resources/links/create`
for new links, `resources/links/:id` when editing an existing row). The form
asks for a **Cover Image**, **Title**, **URL** (validated as a web address),
**Type** and **Description**, plus which **Collections** the link belongs to.
Save to publish it to the list.

  Links point outward — unlike files, they need connectivity to open. Prefer
  file resources for content farmers must reach offline.
</Callout>

## Who can do what

<AccessSummary>
  <AccessRow roles="viewer">Browse the list and open any link — without an editing role the editor opens read-only as **View Resource Link**.</AccessRow>
  <AccessRow roles="editor">See **Add Link** and register new links; edit or delete owned links, while links owned by someone else stay read-only (`resources.editor`).</AccessRow>
  <AccessRow roles="admin">Edit or delete any link, and audit field-app data in [Resources data admin](./data-admin) (`resources.admin`).</AccessRow>
</AccessSummary>
