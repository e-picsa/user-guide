title: Collections

---

**Resources → Collections** groups files, links and other collections into named sets — for example *Weather Resources* or the *PICSA Manual* — which can nest inside parent collections.

The table shows each collection's cover, title and description, how many files and links it holds, and when it was last modified. Clicking a collection cover elsewhere (for example in the Files list) jumps here.

## Who can do what

<AccessSummary>
  <AccessRow roles="viewer">Browse the list and open any collection — without an editing role the editor opens read-only as **View Collection**.</AccessRow>
  <AccessRow roles="editor">See **Add Collection** and create collections or edit any existing one (`resources.editor`) — see [Managing collections](./collections-manage).</AccessRow>
  <AccessRow roles="admin">Additionally delete any collection, and audit field-app data in [Resources data admin](./data-admin) (`resources.admin`).</AccessRow>
</AccessSummary>
