---
title: Collections
description: Group files and links into nested collections for the field app.
---

**Resources → Collections** groups files, links and other collections into named sets — for example *Weather Resources* or the *PICSA Manual* — which can nest inside parent collections.

  src="/screenshots/zm-admin/resources/collections.png"

  ]}
  caption="Resource Collections, 11 collections (Zambia)"
/>

Root-level collections sort first, then the rest by modification date. Clicking a collection cover elsewhere (for example in the Files list) jumps here.

<Callout type="warning">
  The collection editor is currently **under construction** — opening
  **Add Collection** shows a placeholder page. Collections themselves still
  display normally in the field app.
</Callout>
