## Steps

1. Enter a **Title** (required) and an optional **Description** explaining what the collection groups.
2. Add an optional **Cover Image** (jpg, png, svg or webp) so the collection is recognisable in lists and in the field app.
3. Pick the contents in **Collection Contents**: the **Files** tab lists every file in the deployment, the **Links** tab every link. Use search or the **All / Selected** filter to narrow the list, then tick rows to include them — the header counts selected files and links as you go.
4. **Save Collection**. The collection is upserted and appears in the list and in the field app data immediately.

## Editing and deleting

Opening an existing collection shows the same form with its current contents pre-selected. Saving writes the new membership list — unticking a file or link removes it from the collection without deleting the underlying resource. **Delete Collection** removes the collection itself; the files and links it grouped are unaffected.

  releases. Already-downloaded copies on devices are unaffected.
</Callout>

## Who can do what

<AccessSummary>
  <AccessRow roles="viewer">Open any collection, but the form is read-only **View Collection** — save and delete stay hidden.</AccessRow>
  <AccessRow roles="editor">Create new collections and edit any existing one — ownership does not restrict editing, unlike files and links (`resources.editor`). Delete only owned collections.</AccessRow>
  <AccessRow roles="admin">Do everything editors can, and additionally delete any collection (`resources.admin`).</AccessRow>
</AccessSummary>
