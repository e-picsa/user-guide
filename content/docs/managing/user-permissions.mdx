**User Permissions** (requires `deployments.admin`, found under *User Permissions* in the sidebar) manages users for the active deployment: roles, access requests and membership.

## Managing roles

- Each cell toggles that user's role for one feature: empty (no access) → **admin** → **editor** → empty again.
- **Global Admin** is granted only from the row menu, never by accident from the matrix.
- You cannot change your own permissions.

## Access requests and membership

Pending access requests appear for approval with accept/reject actions and an optional response message. **Add User** invites a new member; the row menu removes members or edits their profile.

<Callout type="info">
  Permissions are per deployment — someone who administers Zambia has no
  access to Malawi until added there too.
</Callout>
