**Map Boundaries** (requires `app.admin`, the strictest role) manages the TopoJSON administrative boundaries that power every map in the dashboard — station maps, location labels and the station picker.

## Workflow

1. **View** a level to render its boundaries on the map and check coverage.
2. If a level is **Missing** or stale, **Generate** re-syncs it from the backend (a spinner shows progress).
3. Rename level labels with the edit action so they match local terms (for example Province vs District).

<Callout type="warning">
  Boundary data underpins location names across Crop and Climate pages —
  regenerate carefully and verify maps afterwards.
</Callout>
